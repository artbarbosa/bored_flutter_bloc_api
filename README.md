# Flutter BLoC API Study

Flutter study of API-driven state and interface behavior using BLoC, Equatable and HTTP clients.

## Project scope

A study or technical-challenge implementation from its original development period. It is shared as a portfolio reference; the original implementation and commit history are preserved.

## Stack and SDK

- Flutter and Dart.
- Main declared packages: `flutter_bloc`, `equatable`, `http`, `dio`, `connectivity_plus`, `lottie`.
- Dart SDK constraint from `pubspec.yaml`: `>=2.15.1 <3.0.0`.

Use a Flutter release with a Dart SDK inside that range. Dependency modernization is a separate change from publishing this historical example.

## Run

```bash
flutter pub get
flutter run
```

## Tests

The repository contains 1 Dart test file matching `*_test.dart`. Run the existing suite with a compatible SDK:

```bash
flutter test
```

Test files are learning artifacts; their presence is not a claim that they have passed on a current Flutter release.
